행복기숙사 미니게임 - 모바일 최적화 버전

변경사항
- 모바일 viewport 최적화
- 세로 화면 기준 반응형 처리
- 화면 하단 터치 이동 버튼 추가
- 아이폰/안드로이드 safe-area 대응
- 모바일 터치/스크롤 방지
- 기존 PC 키보드 조작은 유지
- 기존 게임 이미지와 콘텐츠는 그대로 유지

GitHub Pages 업로드 방법
1. 기존 파일을 백업합니다.
2. 이 ZIP 안의 기존 index.html, style.css, game.js와 이미지 파일을 GitHub 저장소에 덮어씌웁니다.
3. GitHub Pages 주소를 휴대폰에서 열어 테스트합니다.
